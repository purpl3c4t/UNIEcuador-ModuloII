# 1.1 Fundamentos de UEBA y LoTL 
---

## Running the UEBA Deep Autoencoder Simulation
This guide explains how to configure your environment and run the PyTorch-based **User and Entity Behavior Analytics (UEBA)** simulation script (`ueba-autoencoder-simulation.py`). 

The script demonstrates how an **under-complete Deep Autoencoder** can establish a behavioral baseline using normal enterprise telemetry and flag sophisticated attacks (such as Living off the Land and Data Exfiltration) based on their **reconstruction error (MSE)**.

---

## 1. Prerequisites & Environment Setup

Before running the script, ensure you have Python 3.8+ installed along with the required scientific computing, deep learning, and visualization libraries.

### Installing Dependencies
Run the following command in your terminal to install all required packages:

```bash
pip install torch numpy pandas scikit-learn matplotlib seaborn
```

*Note: No GPU is required. The simulation runs extremely fast (under 10 seconds) on a standard CPU.*

---

## 2. How to Run the Script

To execute the simulation, navigate to the directory where `ueba-autoencoder-simulation.py` is saved and run:

```bash
python ueba-autoencoder-simulation.py
```

### What Happens During Execution?
1. **Synthetic Telemetry Generation**: The script models **1,000 baseline rows** of normal daytime activity across 5 features (logons, transfers, process spawns, hours, administrative activity) alongside **15 advanced multi-stage attack scenarios** (LotL, exfiltration, and administrative abuse).
2. **Model Training**: A 5-layer under-complete PyTorch Autoencoder is initialized. It is trained for **200 epochs** *strictly* on the normalized normal-behavior data to learn the normal business baseline.
3. **Anomaly Inference**: The model evaluates the full test suite. It computes the **Mean Squared Error (MSE)** between the original inputs and their reconstructed outputs.
4. **Visual & Analytical Output Generation**: The script computes a dynamic anomaly threshold (the 99th percentile of normal data) and exports both a high-contrast scatter plot and a tabular metrics report.

---

## 3. Expected Outputs & Verification

Upon a successful run, the terminal will print:
```text
Simulation finished successfully!
Normal baseline median error: 0.2779
Anomalous median error: 588.1509
```

Additionally, the script generates two key files:

### A. Anomaly Visualization Chart (`reconstruction_error_chart.png`)
* **What it shows**: A scatter plot comparing normal versus malicious activities on a logarithmic scale. 
* **Key indicator**: Normal activities will cluster tightly below the red dashed line (Threshold). LotL attacks, exfiltrations, and account abuses will spike vertically, generating **50× to 5000× higher reconstruction errors**.

### B. Analytical Summary (`ueba_simulation_summary.csv`)
This file contains the statistical distribution of reconstruction errors across different categories:

| Activity Type | Min Error | Median Error | Max Error | Abnormal % |
| :--- | :--- | :--- | :--- | :--- |
| **Normal Behavior** | ~0.001 | ~0.277 | ~5.440 | 1.0% |
| **LotL Attack (Case A)** | ~159.88 | ~588.15 | ~1261.16 | 100.0% |
| **Data Exfiltration (Case B)** | ~795.52 | ~1664.78 | ~5520.91 | 100.0% |
| **Admin Privilege Abuse (Case C)** | ~76.85 | ~98.85 | ~436.50 | 100.0% |

## 4. Tweak & Experiment (Quick Challenges)

The script is highly customizable. Open the python file to attempt the following:
* **Narrow the Bottleneck**: Locate `latent_dim=2` in the script. Try changing it to `latent_dim=1` or `latent_dim=3` to see how tightening the network bottleneck changes the normal baseline reconstruction accuracy.
* **Make an Attack "Stealthy"**: Modify the parameters under `# Case B: Quiet Data Exfiltration` by reducing `data_anom_b` to a smaller value (e.g., standard daylight levels). See if the attacker can bypass the anomaly threshold of **1.76** without being caught.
